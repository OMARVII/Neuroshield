# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in NeuroShield, **do not open a public issue**.

Please report it privately by emailing **omarkhaledvii@gmail.com** with:

- A description of the vulnerability
- Steps to reproduce
- Potential impact

You will receive a response within 72 hours. Critical issues affecting user safety will be prioritized.

## Scope

NeuroShield runs entirely locally with no network requests. Security concerns are primarily:

- Chrome extension permission escalation
- Content script injection or XSS
- Bypass of flash detection that could expose photosensitive users to danger
